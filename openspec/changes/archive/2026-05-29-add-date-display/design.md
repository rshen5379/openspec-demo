## Context

当前主页面仅有浮动操作按钮（FAB）用于打开 AI 对话框，页面本身无任何内容展示。需要在主页面上增加当前日期显示，提升页面的信息量。

## Goals / Non-Goals

**Goals:**
- 在主页面展示当前日期，使用中文本地化格式
- 日期随系统时间自动更新（跨天自动切换）
- 与现有页面布局协调，不影响 FAB 和对话框功能

**Non-Goals:**
- 不涉及日期选择器或日历功能
- 不涉及后端 API 变更

## Decisions

- 使用浏览器原生 `Intl.DateTimeFormat` 进行中文日期格式化，无需引入第三方日期库
- 日期显示放置在页面顶部居中位置，简洁不遮挡其他元素
- 通过 `setInterval` 每分钟检查日期变更，确保跨天时自动更新

## Risks / Trade-offs

- 无显著风险，纯前端展示功能
